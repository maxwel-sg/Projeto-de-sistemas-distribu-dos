# 🏍️ Aplicativo Web de Apoio ao Motoboy

## 📌 Sobre o projeto

O Aplicativo Web de Apoio ao Motoboy tem como objetivo auxiliar no gerenciamento e acompanhamento de pedidos de entrega, permitindo registrar informações dos pedidos, acompanhar seus status e controlar o tempo gasto em cada entrega.

O sistema será desenvolvido inicialmente como um protótipo funcional, utilizando um formulário para simular a inserção de pedidos provenientes de plataformas como Consumer ou Saipos.

## 🎯 Objetivo

Desenvolver uma aplicação web que permita acompanhar o ciclo de vida de um pedido, desde seu recebimento até a confirmação da entrega ao cliente.

## ⚙️ Funcionalidades

- **Cadastro de pedidos:** formulário para inserir os dados do pedido, estabelecimento, cliente, endereço, itens e forma de pagamento.
- **Gerenciamento de status:** acompanhamento das etapas do pedido.
- **Cronômetro de entrega:** registro do tempo entre a saída para entrega e sua conclusão.
- **Mapa de localização:** visualização do endereço do cliente e apoio ao deslocamento do entregador.
- **Histórico de entregas:** consulta aos pedidos concluídos e seus respectivos tempos de entrega.

## 🔄 Ciclo de vida do pedido

1. Recebido.
2. Em preparação.
3. Pronto para retirada.
4. Saiu para entrega.
5. Entregue.

## 🛠️ Tecnologias previstas
